# net_surgeon

**Русский** | [English](README.en.md)

Обход блокировок сайтов провайдером (DPI) для **Windows**, **Linux** и
**Android**. Программа сама подбирает рабочую технику обхода для каждого
сайта: проверяет несколько техник и выбирает по статистике, а не по одной
случайной удаче.

YouTube, Discord, нейросети, закрытые для России, Telegram.

## Что умеет

- **Обходит DPI** по имени сайта: делит TLS-приветствие на несколько
  записей, режет пакет посередине имени, меняет порядок кусков (disorder),
  вставляет OOB-байт.
- **Сам подбирает технику** для каждого сайта, запоминает её и перемеряет,
  если она перестала работать.
- **Не требует настройки:** на Linux и на Windows (от администратора)
  перехватывает трафик всей машины, без прав администратора на Windows сам
  включает системный прокси, на Android работает как VPN без root.
- **Шифрует DNS** (DoH), чтобы провайдер не подменял адреса сайтов.
- **Открывает нейросети,** закрытые для России (ChatGPT, Claude, Gemini,
  Grok, Copilot), через умный DNS.
- **Telegram** — через ваш собственный бесплатный воркер на Cloudflare, если
  провайдер блокирует его адреса целиком ([инструкция](cloudflare/README.md)).

**Чего не умеет:** менять ваш IP-адрес. Если сервис сам не пускает из
России, поможет только VPN (кроме нейросетей из списка выше).

## Быстрый старт

### Windows

1. Скачайте архив для Windows, распакуйте в любую папку.
2. Запустите `net_surgeon.exe`: правый клик → «Запуск от имени
   администратора». Так через обход идут все программы (прозрачный режим).
   Можно и обычным двойным щелчком, тогда только браузеры (см. ниже).
3. Если появится «Система Windows защитила ваш компьютер», нажмите
   «Подробнее → Выполнить в любом случае»: у программы нет платной подписи.

Пока окно открыто, трафик идёт через обход. Закройте окно — всё вернётся
как было.

> **Прозрачный режим** включается сам, если программа запущена от
> администратора: драйвер [WinDivert](https://reqrypt.org/windivert.html)
> (он лежит в архиве) заворачивает в обход всё то же, что и в Linux:
> HTTPS всех программ, в том числе приложения Discord, QUIC, по которому
> Chrome открывает YouTube, звонки (Discord, Telegram, WebRTC) и DNS.
> Без прав администратора работает только системный прокси: через обход
> идут браузеры и программы, которые берут прокси из настроек Windows.
> Чтобы настраивать прокси вручную, поставьте `system_proxy = false`
> в `config.toml`, а чтобы выключить перехват, `transparent_port = 0`.
>
> Как и zapret, программа видит только начало каждого HTTPS-соединения
> и первый ответ сервера, а из QUIC и звонков — только первые пакеты;
> остальной трафик, в том числе голос и игры, идёт мимо неё, и пинг от
> перехвата не растёт. Из-за этого в прозрачном режиме нет двух техник,
> которые меняют число байт в потоке (TLS-записи и OOB); вместо них
> есть приманка (fake), которой без прав администратора нет.
>
> Антивирус может ругаться на WinDivert: это драйвер перехвата пакетов,
> тот же, что у GoodbyeDPI и zapret.

### Linux

```sh
curl -LO https://github.com/rozinanime-sketch/net_surgeon/releases/download/v0.7.0/net_surgeon-0.7.0-x86_64-linux.tar.gz
tar xzf net_surgeon-0.7.0-x86_64-linux.tar.gz
cd net_surgeon-0.7.0
./run.sh
```

Сборка статическая и работает на любом дистрибутиве. При первом запуске
скрипт один раз спросит пароль `sudo`, чтобы выдать программе права на
перехват. Для выхода нажмите `q`: перехват снимется сам.

Нужны `nft` (nftables), `iproute2` и `setcap` (пакет `libcap` в Arch,
`libcap2-bin` в Debian и Ubuntu).

### Android

Установите APK и нажмите «Включить», затем согласитесь на подключение VPN.
Это не настоящий VPN: трафик не уходит с телефона. Подробнее — в
[android/README.md](android/README.md).

### Свои сайты

Обход включается только для сайтов из `bypass_domains.txt`, по одному на
строку. Поддомены учитываются: `youtube.com` покрывает и `m.youtube.com`.
Добавить сайт можно и прямо в программе, в меню «Домены».

## Если не работает

| Что случилось | Что делать |
|---|---|
| **Windows:** после выхода пропал интернет | «Параметры → Сеть и Интернет → Прокси-сервер» → выключить прокси. Программу, видимо, закрыли через диспетчер задач |
| **Windows:** в логе «порт … не принимает перехваченные соединения» | Брандмауэр или антивирус не пускает соединения на порт прозрачного режима (1083): через него идёт Telegram, если задан ретранслятор. Разрешите порт для `net_surgeon.exe` |
| **Linux:** после выхода пропал интернет | `./run.sh off` |
| Сайт не открывается | Проверьте, что он есть в `bypass_domains.txt`. Если есть — запустите «Диагностику» для него или удалите `strategies.txt`, чтобы перемерить всё |
| Ничего не обходится | Выключите VPN: через него провайдер трафик не видит, и обход бесполезен |
| Сайт пишет, что недоступен в вашей стране | Это блокировка самим сайтом, а не провайдером. Поможет только VPN |

Программа проверена в одной сети. Если у вас не работает,
[опишите проблему](https://github.com/rozinanime-sketch/net_surgeon/issues)
и приложите лог из окна программы.

./run.sh plain        # только прокси-порты, без перехвата

| Что | Адрес |
|---|---|
| HTTP/HTTPS | `127.0.0.1:1080` |
| SOCKS5 | `127.0.0.1:1081` |

<details>
<summary><b>Linux: как устроен перехват и почему сеть не должна пропасть</b></summary>

Перехватываются HTTPS (TCP/443), QUIC (UDP/443), DNS (UDP/53) и UDP
звонков: голос Discord (порты 50000–65535), STUN и серверы Telegram. Перед
звонком уходит мусор, как в SOCKS5-режиме; выключается `calls = false`.
Правила лежат в таблице nftables, которая принадлежит процессу программы:
ядро удаляет её, как только процесс завершился, даже после `kill -9` или
падения. Поэтому sudo
нужен только один раз после скачивания или сборки — выдать программе права
(`cap_net_admin`) и группу `nsproxy`.

Если в системе нет `nft` или `getcap` (или задано `NET_SURGEON_LEGACY=1`), скрипт идёт
старым путём через `iptables`: спрашивает sudo при каждом запуске, снимает
правила при выходе и держит сторожа на случай `kill -9` или закрытого окна.
Если на этом пути после выхода пропал интернет:

1. `./run.sh status` — есть ли правила;
2. `./run.sh off` — снять их. Снимаются только свои правила, правила Docker
   и VPN не трогаются;
3. если sudo не пускает — перезагрузитесь: правила живут только в памяти.

Не используйте `iptables -F`: он снесёт и правила Docker, VPN и файрвола.

Предупреждения старого пути:

| Сообщение | Что значит | Что делать |
|---|---|---|
| `TPROXY недоступен` | В ядре нет модуля `xt_TPROXY` | Ничего: QUIC пойдёт мимо обхода, браузер откатится на TCP |
| `Не удалось выдать полномочия` | Не сработал `setcap` | Поставьте `libcap` / `libcap2-bin` |
| `IPv6 не перехватывается` | Нет `ip6tables` или nat для IPv6 | Ничего: работает только по IPv4 |
| `не задан doh_bootstrap_ip` | Релей DNS не узнает адрес провайдера DoH | Впишите в `config.toml` IP-адрес сервера из `doh_provider` |
| `Не удалось запустить сторожа` | Нет `setsid` | Перехват снимется при обычном выходе; после сбоя — `./run.sh off` |

</details>

<details>
<summary><b>Сборка из исходников</b></summary>

Нужен Rust 1.88 или новее (проще всего через [rustup](https://rustup.rs)).

```sh
git clone --branch v0.7.0 https://github.com/rozinanime-sketch/net_surgeon.git
cd net_surgeon
./run.sh
```

`run.sh` сам соберёт программу при первом запуске и пересоберёт, если код
изменился. Без `--branch` скачается текущая версия из `main`, а не релиз.
Сборка Android-приложения описана в [android/README.md](android/README.md).

</details>

<details>
<summary><b>Файлы</b></summary>

- `bypass_domains.txt` — сайты, для которых включается обход.
- `smart_dns_domains.txt` — сайты, адреса которых узнаются через умный DNS.

  Списки можно править. Домены, добавленные в новой версии, программа
  дописывает в них сама, по одному разу: удалённые вами не вернутся.
- `config.toml` — настройки. У каждого параметра есть комментарий, но лучше
  не менять их без нужды.
- `strategies.txt` — подобранные техники. Создаётся сам; удалите, чтобы всё
  перемерить с нуля.

</details>
