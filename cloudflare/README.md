# Ретранслятор Telegram на Cloudflare

У части операторов IP-адреса Telegram заблокированы целиком: до `149.154.*`
и `91.108.*` не доходит даже установка соединения. Маскировка здесь не
помогает, пакеты просто не доезжают. Веб-вход `kws*.web.telegram.org` стоит на
тех же адресах и заблокирован так же.

Поэтому net_surgeon заворачивает соединения Telegram в WebSocket до вашего
собственного воркера на Cloudflare, а воркер уже из сети Cloudflare
соединяется с серверами Telegram:

```
Telegram → net_surgeon → wss://<ваш воркер>.workers.dev → серверы Telegram
```

- Адреса Cloudflare не блокируют: на них половина интернета.
- Воркер видит только зашифрованный поток MTProto, прочитать переписку нельзя.
- Воркер соединяется **только** с адресами Telegram, иначе он был бы
  открытым прокси для любого, кто узнает его адрес.
- Настраивать прокси в самом Telegram не нужно: net_surgeon узнаёт его
  соединения по IP.

## Развернуть свой воркер

Нужен бесплатный аккаунт [Cloudflare](https://dash.cloudflare.com/sign-up)
(почта, карта не нужна) и Node.js.

```sh
cd cloudflare
npx wrangler login     # вход через браузер на этом компьютере
npx wrangler deploy
```

Если `deploy` попросит зарегистрировать поддомен `workers.dev`, сделайте это
в панели Cloudflare (Workers & Pages) и повторите. Имя лучше взять случайное.

В конце `deploy` напечатает адрес вида
`https://net-surgeon-tg.<поддомен>.workers.dev`. Сертификат для нового
поддомена выпускается несколько минут.

Запишите адрес в `telegram_relay.txt` в корне проекта (файл в `.gitignore`):

```
net-surgeon-tg.<поддомен>.workers.dev
```

и перезапустите прокси. В логе появится «Telegram через ретранслятор …».
На Android нажмите в приложении «Telegram», вставьте адрес, сохраните и
перезапустите обход. Если собираете приложение сами
(`./android/build.sh install`), файл из корня проекта попадёт в него сам; в
релизную сборку (`release`) он не кладётся никогда.

## Ограничения

- **Звонки.** Голос идёт по UDP, а воркер умеет только TCP. Сообщения, фото,
  видео и установка звонка работают, голос — нет.
- **Лимит бесплатного тарифа** — 100 000 запросов в сутки. Запрос — это одно
  соединение Telegram, а не одно сообщение: приложение держит несколько
  долгих соединений и открывает новые в основном при смене сети. Посмотреть
  расход: панель Cloudflare → Workers & Pages → net-surgeon-tg → Metrics.
